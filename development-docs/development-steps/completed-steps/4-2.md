# 4-2 — обновление сервера и три доказательства из четырёх

**Закрыт 2026-08-24.** Второй подшаг шага 4. Первый выход работы на боевой сервер.

## Что нашлось до сборки

Смотрел сервер, а не собирал вслепую. Слот **уже стоял на `8c7b731`** — мой коммит подтянулся сам, и
`app/api/passport/route.ts` в слоте лежал. А `.next` был собран **23 августа**:

| Факт | Значение |
|---|---|
| `git` слота | `8c7b731` — мой коммит |
| `.next` собран | `2026-08-23 23:13` |
| `NEXT_PUBLIC_GIT_COMMIT` в слоте | **метки НЕТ** — отсюда `commit: null` в `/api/health` |
| `/tmp/fractera-deploy.lock` | есть, 0 байт, 21:19; `.lock.pid` отсутствует; **процессов сборки нет** |

То есть код приехал, а сборки не было: ровно та работа, которую шаг и заказывает — **обновление**.
Осиротевший замок разбирать руками не пришлось: `deploy.sh` прошёл сам, и после сборки
`PANEL_BUILD=idle`.

## Первая сборка упала — на моём коде

```
БЕДА: типографика разъезжается
  заботок оформлен вручную, мимо примитива:
    …/passport-view/index.client.tsx:46,47,48
===TYPOGRAPHY_FAILED===
===BUILD_FAILED===   EXIT=1
```

В карте markdown стояли три заголовка, оформленные классами руками. Шкала в проекте одна и живёт в
`components/ui/typography.tsx`. Починил в **источнике** (границы шага это и требуют): `H1/H2/H3/H4` и
`P`, `variant="ui"` — паспорт рабочий экран, а не витрина; классы остались только на отступы.

**Почему не поймал локально:** прогонял гейты **выбранным списком**, а `check:typography` в него не
попал. Список гейтов ведёт `prebuild` в `package.json`, а не моя память. Записано в `ANTI-PATTERNS.md`.

**Второй раз тот же гейт поймал мой КОММЕНТАРИЙ:** в объяснении я процитировал образец нарушения
дословно, а сторож построчный и не отличает пример в тексте от кода. Переписал словами.

## Два ложных провала, которые чуть не увели чинить целое

Прогнав `npm run prebuild` целиком, получил ещё два падения — и ни одно не было настоящим:

| Гейт | Что сказал | Что на деле |
|---|---|---|
| `check:config-schemas` | восемь схем «устарели» | содержимое **идентично**, расходятся только переводы строк: git на Windows выдаёт CRLF, генератор пишет LF |
| `check:blocks-map` | каталог секций разошёлся с кодом | то же самое, но `\r\n` спрятан **внутри строк JSON** — глазами не видно |

Оба на сервере (Linux, LF) зелёные — что и подтвердила сборка. Ловушка не в диагнозе, а в лечении:
послушавшись совета гейта, я получил бы девять изменённых файлов чистого шума. Проверил сравнением без
переводов строк, откатил, записал в `ANTI-PATTERNS.md`.

## Доказательства — четыре плоскости, три ответа получены

**① Доставка: `commit` в `/api/health` равен моему хэшу.**

```
{"ok":true,"commit":"3b24467","builtAt":"2026-08-24T19:38:45.282Z","langs":["en","ru"]}
```

Негативный контроль — тот же адрес **до** сборки: `{"commit":null,"builtAt":"2026-08-23T21:12:37Z"}`.
🔒 `null` — подпись сборки без метки (`use-deploy` §4); метку ставит `deploy.sh`, и до этого шага её в
слоте не было вовсе.

**② Держатель порта: `status.sh` → 0.**

```
PORT_OWNER=pm2   PM2_STATUS=online   PM2_RESTARTS=2
CHAIN pid=3773120 comm=next-server ← 3773119 sh ← 3773092 npmrunstart
UPTIME_MS_1=8760  UPTIME_MS_2=12299  UPTIME_GROWING=yes
```

Слушатель — потомок pm2 по цепочке `ppid`, uptime растёт между двумя замерами. Негативный контроль —
до сборки uptime был 33 282 801 мс и не менялся по природе: цифра сбросилась в 8 760, то есть процесс
действительно перезапущен, а не «выглядит живым».

**③ Гость: объяснение и путь входа, а не тупик.**

```

$ curl -i https://aifa.dev/api/passport              → HTTP/1.1 401 Unauthorized
```

Содержимого паспорта в отданной гостю разметке: `Закон старта` 0 · `ChatPush` 0 · `YCLIENTS` 0 ·
`со слов Филиппа` 0 · `Мера успеха` 0. Негативный контроль на том же файле: `Паспорт проекта` 1,
`Загружаю паспорт` 1, `administration/passport` 1 — поиск работает, значит нули это отсутствие текста.

**④ Архитектор видит паспорт — НЕ ПОЛУЧЕНО.** Требует сессии Ромы; своей у меня нет, а вводить чужие
учётные данные нельзя. Корпус называет ровно этот случай: недостижимый пруф объявляется недостижимым и
не подменяется лёгким. Проверяется одним входом в оставленной открытой вкладке.
