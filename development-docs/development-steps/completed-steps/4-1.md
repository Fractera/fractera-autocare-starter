# 4-1 — предусловие и транспорт: код в GitHub, ключ на месте

**Закрыт 2026-08-24.** Первый подшаг шага 4. Две остановки, обе на предусловиях, обе сняты Ромой.

## Остановка первая — код не был отправлен

Шаг открывается проверкой «репозиторий отправлен в GitHub». Разошлись:

```
$ git rev-parse --short HEAD        →  462aaac
$ git ls-remote origin main         →  46508d5
```

🔒 **Расхождение было хуже, чем описано в плане.** План говорил «6 коммитов, и в них весь паспорт со
страницей». На деле коммитов было **8**, и **кода шага 3 не было ни в одном**:

```
$ git cat-file -e HEAD:app/api/passport/route.ts
fatal: path 'app/api/passport/route.ts' exists on disk, but not in 'HEAD'
$ git ls-tree -r --name-only HEAD | grep -c "administration/passport"
0
```

Все 8 коммитов — Ромины, в них планы шагов и документы. Собери мы тогда — сервер собрал бы код без
страницы, сборка была бы зелёной, а сайт пустым.

**Почему код не был в коммитах:** агент не коммитит без слова владельца, и слова не было. Сказать об
этом следовало в конце шага 3, а не когда об это споткнулся шаг 4.

Рома сказал «закоммить всё и отправь» — сделано одним коммитом (17 файлов, секретов ноль, `.env.local`
под `.gitignore`), Ромины 8 уехали вместе с ним.

⚠️ **`git push` от имени окружения не проходит:**

```
remote: Permission to mintallart-debug/roma-autozabota-v1.git denied to bolshiyanov.
fatal: … 403
```

Git аутентифицируется как `bolshiyanov`, прав у него нет. Прошло токеном `USER_GITHUB_ACCESS_TOKEN` из
`.env.local` — он принадлежит этому репозиторию, панель кладёт его туда сама, `CLAUDE.md` называет его
законным. В конфиг репозитория токен не записывал, в вывод не печатал.

## Остановка вторая — транспорта не было

```
$ bash scripts/server/deploy.sh
scripts/server: нет переменной FRACTERA_SSH_HOST … [код возврата 2]
```

🔒 **Вторая предпосылка плана — «`FRACTERA_SSH_*` нет и не нужны» — тоже неверна.** Режим панели идёт
по SSH точно так же: дверь сборки — `http://localhost:3002/api/deploy`, то есть **localhost самого
сервера** (`deploy.sh:65`), и весь удалённый блок уходит в `fx_ssh` (`deploy.sh:146`).
`FRACTERA_DEPLOY_SECRET` решает, **кто собирает**, а не **как туда попасть**.

Второй транспорт в обход `deploy.sh` не изобретал — запрещено и границами шага, и `use-deploy` §2.

Рома прислал выгрузку окружения из панели. Перед заменой файла сверил составы, чтобы ничего не
потерять: пропадала одна переменная `DEPLOY_SECRET` (без префикса) — **её не читает ни одна строка
кода**, проверено поиском. Прежний `.env.local` сохранён в scratchpad, вне репозитория.

**Побочная хорошая новость:** в выгрузке **дублей нет** — ни `REMOTE_DATA_URL`, ни `DATA_SECRET`.
`REMOTE_DATA_URL=https://data.aifa.dev` в одном экземпляре и с верным значением: починка панели
доехала. Дефект, который я нашёл в шаге 2, закрыт.

Ключ развёрнут из `FRACTERA_SSH_KEY_B64` в `.fractera-ssh/fractera-agent-key` (419 байт, заголовок
`BEGIN OPENSSH PRIVATE KEY`), права 600. Папка под `.gitignore` — проверено.

## 🔴 Находка, требующая решения Ромы

Читая состояние слота, распечатал его `git remote get-url origin` — **и в адресе оказался живой токен
GitHub в открытом виде**. Он лежит так в `/opt/fractera/app/.git/config` на сервере и попал в эту
переписку. Токен рекомендую перевыпустить; после перевыпуска панель перезапишет его сама.

**Привычка, которую фиксирую:** прежде чем печатать в лог адрес удалённого репозитория, помни, что в
нём может быть встроен секрет. Спрашивать `git remote -v` на сервере — то же самое, что печатать
переменную окружения.

## Доказательство

```
$ git rev-parse --short HEAD        →  8c7b731
$ git ls-remote origin main         →  8c7b731
$ git cat-file -e HEAD:app/api/passport/route.ts   → есть в HEAD
файлов administration/passport в HEAD: 5
```

Что доказывает: предусловие шага выполнено — код, а не только документы, лежит в GitHub.
Негативный контроль — тот же `cat-file` на том же пути **до** отправки давал
`exists on disk, but not in 'HEAD'`. Один инструмент, два разных ответа до и после.

Транспорт: `status.sh` отработал по SSH и вернул состояние сервера (код возврата 0) — канал открыт.
