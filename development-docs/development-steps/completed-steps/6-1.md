## Дерево маршрутов

```
/                          app/page.js              редирект на /dashboard
/login                     app/login/page.js
/connect/yclients          app/connect/yclients/page.js
(app)  ← единственная группа исходника
  /dashboard   /tasks   /patients   /patients/[id]   /messages
  /scenarios   /services   /analytics   /audit   /users
```

## Группировка — одна скобочная группа и один сторож

`(app)` — единственная скобочная группа. Даёт девяти маршрутам общий макет: боковая рейка на 200px,
девять пунктов навигации с встроенными SVG-иконками, подпись клиники из `/api/me`, кнопка «Выйти».
Пункт `/users` помечен `adminOnly: true` и фильтруется из меню при `me.role !== "admin"`.

Второй механизм — `middleware.js` с `matcher: ["/((?!_next/static|_next/image|favicon.ico).*)"]`:
через него проходит каждый запрос.

## Тип каждого маршрута и признак

| Маршрут | Тип | По какому признаку |
|---|---|---|
| `/` | серверный, только `redirect()` | 4 строки, нет клиентской директивы |
| `/login` | `"use client"` | первая строка файла |
| девять маршрутов `(app)` | `"use client"`, каркас предрендеривается, данные приезжают после монтирования | `"use client"` + `useEffect` в **10 файлах из 10**; серверных обращений к данным в файлах страниц нет |
| `/patients/[id]` | динамический сегмент | `[id]` в пути, `generateStaticParams` — **ноль вхождений во всём дереве** |
| `/tasks` | остаётся предрендеримым | `useSearchParams` обёрнут в `<Suspense>` (`page.js:15`) |
| `/connect/yclients` | серверный, на каждый запрос | `await searchParams` (`:32`) и запись в базу прямо в рендере (`:44-56`) |

Модальные окна объявлены внутри файлов страниц: 12 вхождений `<Modal>` на шести страницах

## Что публично по коду

`middleware.js:4` — `PUBLIC = ["/login", "/api/auth/login", "/connect/yclients", "/api/yclients",
"/api/chatpush"]`. Всё остальное требует валидного JWT из cookie `care_session`: `/api/*` → `401`,
страница → редирект на `/login`.

**Публичны три адреса страниц и две двери интеграций.** Остальные девять маршрутов — за входом.
Внутри них роль различает один маршрут: `/users` (скрыт из меню и закрыт в двери).

## Доказательство

```
$ grep -rc "generateStaticParams" app --include=page.js | grep -v ':0' | wc -l
0
$ grep -rl "useEffect" app --include=page.js | wc -l
10
$ grep -n "PUBLIC = " middleware.js
4:const PUBLIC = ["/login", "/api/auth/login", "/connect/yclients", "/api/yclients", "/api/chatpush"];
```

Негативный контроль: тот же поиск на `useEffect` не находит его в `connect/yclients/page.js` и
`app/page.js` — то есть различает серверные файлы от клиентских, а не помечает всё подряд.
