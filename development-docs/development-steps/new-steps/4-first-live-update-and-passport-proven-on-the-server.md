паспорт.

## 🛑 Предусловие, без которого шаг НЕ начинается

**Репозиторий должен быть отправлен в GitHub.** Локально `ef669e6`, в GitHub `46508d5` — шесть
коммитов разницы, и в них весь паспорт со страницей. Сервер берёт код только из GitHub.


Разошлись — **остановись и скажи Роме.** Не отправлено = работать не с чем.

## 🔒 Это ОБНОВЛЕНИЕ, а не развёртывание. Разница стоит сервера

| Слово | Что делает |
|---|---|
| **обновление / сборка** | пересобирает код уже стоящей службы. **Это наш случай** |
| **развёртывание** | стирает слот тем же `rm -rf`, что ставит платформу заново, и клонирует репозиторий начисто |

🔒 **Полного развёртывания НЕ запускать.** Оно сотрёт слот и вернёт его из GitHub — и если в GitHub
чего-то нет, оно пропадёт навсегда. Называть обновление развёртыванием тоже нельзя: Рома читает твоё
слово как описание того, что уже произошло с его машиной.

## Чем разворачивать — проверено, канал есть

`FRACTERA_DEPLOY_SECRET` в окружении **присутствует**, значит по `use-deploy` §3 собирает **панель**:
своя очередь, журнал развёртываний, откат на последнюю рабочую сборку. `FRACTERA_SSH_*` нет и не нужно.

Инструмент — `scripts/server/deploy.sh`, свой `ssh`/`scp` не изобретать.

⚠️ **В `use-deploy` §6 есть устаревшее утверждение** — «у слота нет `origin`». Проверено чтением
сервера 2026-08-24: **origin есть**, слот указывает на этот же репозиторий. На твою работу это не
влияет, но не строй на той фразе рассуждений.

## Что доказать — четыре ответа, а не «сайт открылся»

**Доставка (по `use-deploy` §4):**

1. `commit` в `/api/health` равен твоему хэшу — отвечает именно твоя сборка;
2. `status.sh` даёт 0 — порт держит pm2 или его потомок, `uptime` растёт между замерами.

**Паспорт — два ответа приёмки шага 3, которые ты честно оставил недоказанными:**

3. **гость** на `/ru/administration/passport` получает объяснение и путь входа, а не тупик;
4. **архитектор** видит содержимое паспорта.

🔒 Лог сборки доказательством не является ни для одного из четырёх.

## Границы

- правишь только слот и только через канал панели; **никакого `next start` руками** — так рождаются
  сироты на порту;
- дефект нашёлся — чинишь в ИСТОЧНИКЕ и доставляешь, а не правишь на сервере;
- сборка упала — не собирай повторно вслепую: код возврата берётся у `npm`, а не у `tail`;
- **ничего не удаляешь** из существующих маршрутов: по решению Ромы удаление идёт последним.
